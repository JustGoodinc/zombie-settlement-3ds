# Menu Flowchart

The full flowchart and screen table live in [UI_SCREEN_INDEX.md](UI_SCREEN_INDEX.md), kept together so they cannot drift apart.

Navigation rules: every screen is reachable from the HUD or Main Menu, B always backs out, START resumes from Pause, the shoulder buttons switch tabs, and destructive actions (overwrite, delete, load over progress, reject, quit) always ask for confirmation.
